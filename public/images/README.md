# Photos go here

Drop these files in this folder. The site picks them up automatically, and anything missing falls back to a placeholder.

| File | What | Notes |
|---|---|---|
| `hero.jpg` | Main portrait (shows through the letters of the name) | Facing camera, eyes level, chest-up, plain dark background, strong side light. At least 4000px tall. It's turned black and white by the site, so colour is fine. |
| `football.jpg` | Football: action or team photo | Any quality. Old scans are fine. Shown in black and white. |
| `diary.jpg` | A real page from the diary | Flat phone photo in good light. Blur anything private first. |

Keep file names exactly as above (lowercase, `.jpg`).
